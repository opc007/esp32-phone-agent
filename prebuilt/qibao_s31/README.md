这一版能做的事：语音连上小智，唤醒词是「七宝妹妹 / 七宝 / 你好七宝」；点右上角或说打开摄像头才出实时小窗；问是不是岗哥、画面里有什么时，本机人脸加云端看图，看到可乐或高糖零食会温柔提醒。开机不加载 TF 卡上那份大物品模型，预览里也不定时认物。

重烧：

```bash
prebuilt/qibao_s31/flash.sh /dev/cu.usbserial-XXXX
```

先核对这个口属于上面的 CP2102N。脚本拒绝 `usbmodem`。它只写 app，不写 bootloader、分区表、ota_data、assets，也不擦 NVS。TF 卡上的人脸特征和物品模型文件保持不动。
