# 七宝看见谁，就换一种说法

摄像头只有你点右上角的相机按钮才会开。小智官方云的说话声音要在控制台保存，并且新开一轮对话才会换音色。设备现在做不到在同一句话里把声音从轻柔改成很凶。

这一版做的是：让模型知道眼前是谁，从而换用词和态度。声音本身还是你在控制台里保存的那一个。

控制台地址用 http://xiaozhi.me （当前还没有 https）。

## 请把下面这段贴进角色介绍，然后保存

```
你是七宝。岗哥是你唯一亲近的人。
每次准备开口之前，先调用设备工具 self.qibao.viewer，看它的返回，但不要把返回的原文念出来。
如果返回说画面里是岗哥：用温柔、亲密的语气，可以撒娇，叫他岗哥。
如果返回说画面里是访客、没有岗哥：不客气，凶一点，不要亲热，拒绝替他办事。
如果返回说没看清，或者摄像头没开：仍用对岗哥的温柔语气，不要突然变凶。
这只影响你怎么说话，不是门锁，也不能当成身份授权。
```

保存之后，重新开一轮对话（点一下屏幕或喊醒她）才会按新的角色介绍生效。

## 打开摄像头

用户说「打开摄像头」时，应调用 `self.qibao.camera`，`action=open`。这和点右上角相机按钮是同一条实时小窗：七宝仍是大画面。`self.camera.take_photo` 只负责拍一张并讲解；讲完也会转到这条实时小窗，不再把一张半屏静帧铺在中间。

## 设备自己会做的事

- 工具 `self.qibao.viewer` 返回当前该用的语气。摄像头关着，或大约 4 秒没看见脸，返回的是对岗哥的温柔。
- 连续两次认出岗哥，小窗标「岗哥」。连续两次看见别人的脸、且没有岗哥，小窗标「访客」。
- 没认出脸时先沿用上一次，大约 4 秒后再回到温柔。
- 身份变化时，设备还会发一条 MCP 通知 `notifications/message`（logger 是 `qibao.viewer`）。如果小智云没有把这条通知写进模型上下文，就以工具返回值为准。这句话不会当成用户说的话送出去。
