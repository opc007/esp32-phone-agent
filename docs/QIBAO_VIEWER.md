# 七宝看见谁、看见什么

摄像头只有点右上角的相机按钮，或说「打开摄像头」才会开。小智官方云的说话声音要在 https://xiaozhi.me 控制台保存，并且新开一轮对话才会换音色。设备做不到在同一句话里把声音从轻柔改成很凶。

这一版让模型知道眼前是谁、画面里有什么东西，从而换用词。声音本身还是控制台里保存的那一个。

## 请把下面这段贴进角色介绍，然后保存

控制台：https://xiaozhi.me

```
你是七宝。岗哥是你唯一亲近的人。
每次准备开口之前，先调用设备工具 self.qibao.viewer，也可以调用 self.qibao.see。看返回，但不要把返回的原文念出来。
如果返回说画面里是岗哥：用温柔、亲密的语气，可以撒娇，叫他岗哥。
如果返回说画面里是访客、没有岗哥：不客气、凶一点，不要亲热，拒绝替他办事。
如果返回说没看清，或者摄像头没开：仍用对岗哥的温柔语气，不要突然变凶。
如果返回里有物品名称，用中文告诉用户你看到了什么。
这只影响你怎么说话，不是门锁，也不能当成身份授权。
用户说「记住我的脸」「登记岗哥」时，调用 self.qibao.face，action=enroll。
用户问「你看到什么」时，调用 self.qibao.see。
```

保存之后，重新开一轮对话才会按新的角色介绍生效。

## 打开摄像头

说「打开摄像头」，或点右上角相机按钮。七宝仍是大画面，摄像头在右上角实时小窗。点小窗对调大小。再说「关掉摄像头」或点小窗上的关闭标记。

## 认人

主人特征优先用 TF 卡上已经保存的 `/sdcard/qibao/owner.feat`。卡上已经有岗哥的特征时，不用重新登记。

第一次认识、或要换一张脸时：

1. 打开摄像头，正对镜头。
2. 说「记住我的脸」，或在串口敲 `qenroll`。
3. 成功后特征写入 TF 卡。画面里没有稳定人脸时会失败，正对镜头再来一次。

之后摄像头开着，大约每 2 秒看一次。连续两次认定才把小窗标成「岗哥」或「访客」。正在说话时先不跑，免得挤掉声音。这不是门锁。

## 认物

用乐鑫 COCO 80 类里的 YOLO11n，输入 320。ESP32-S31 用官方 `models/p4` 这份权重，没有单独的 s31 文件。模型大约 2.9MB，app 分区放不下，所以放在 TF 卡 `/sdcard/qibao/coco/`。第一次敲 `qobj` 或问「你看到什么」时才下载，失败可以再试。预览循环不会自己反复下载。预览循环不再认物，避免画面一顿一顿。只有敲 `qobj` 或问「你看到什么」才加载。开机不预加载物品模型：即使内部内存还有大约 18 万，加载仍会把语音挤重启。内存不够时 `qobj` 会说明这次不跑。

串口敲 `qobj` 可以立刻认一次。小智问「你看到什么」时走 `self.qibao.see`。

## 明天早上怎么看

打开摄像头，站到镜头前。小窗应标「岗哥」。换一个人，应标「访客」。语气要在 https://xiaozhi.me 贴上上面那段，并新开一轮对话后才会变。问「你看到什么」时，内部内存不够安全加载这块 2.9MB 物品模型，会说明这次不跑，不会为了认物把语音挤重启。若小窗是黑的，或开着摄像头画面还在连续抖（不是偶尔顿一下），告诉开发的人。这次串口只能证明不再每 5 秒加载物品模型，不能代替看屏幕。
